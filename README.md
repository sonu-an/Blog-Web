# SONU Blog

> 만들고, 부딪히고, 기록합니다.

React, Go, Java로 무언가를 만들며 배운 것들을 정리하는 개인 블로그입니다.
직접 만들면서 배운 것, 헷갈렸던 것, 다시 찾아볼 것들을 기록합니다.

## 다루는 주제

- **Frontend** — React, TypeScript, Next.js
- **Backend** — Java, Go

## 구성

- **홈** — 블로그 소개와 최근 글
- **글** — 카테고리별 글 목록과 상세 페이지
- **소개** — 블로그 운영자 소개

## 기술 스택

- React, TypeScript, Vite
- React Router
- Tailwind CSS
- Bun
